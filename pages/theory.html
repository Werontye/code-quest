HTML - HyperText Markup Language

Язык гипертекстовой разметки для создания структуры веб-страниц. HTML определяет содержимое и семантику страницы.

📌 Структура HTML-документа

Каждый HTML-документ состоит из обязательных элементов:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Описание страницы для SEO">
    <meta name="keywords" content="ключевые, слова">
    <meta name="author" content="Автор">
    <title>Заголовок страницы</title>
    <link rel="stylesheet" href="styles.css">
    <link rel="icon" href="favicon.ico">
</head>
<body>
    <!-- Видимое содержимое страницы -->
    <script src="script.js"></script>
</body>
</html>

Подробное описание элементов:

ЭлементОписаниеОбязательный
<!DOCTYPE html>Объявление типа документа. Указывает браузеру использовать HTML5. Должен быть первой строкой.Да
<html>Корневой элемент. Атрибут lang указывает язык страницы (важно для SEO и accessibility).Да
<head>Контейнер для метаданных: заголовок, стили, скрипты, мета-теги. Не отображается на странице.Да
<meta charset>Кодировка документа. UTF-8 поддерживает все символы, включая кириллицу и эмодзи.Да
<meta viewport>Настройка отображения на мобильных устройствах. Без него сайт будет масштабироваться неправильно.Да
<title>Заголовок вкладки браузера. Важен для SEO (до 60 символов).Да
<body>Содержит всё видимое содержимое страницы.Да

display: inline;          /* строчный (span, a) - по размеру контента */
display: inline-block;    /* строчно-блочный - строчный с размерами */
display: none;            /* скрыть полностью */
display: contents;        /* убрать контейнер, оставить детей */

display: flex;            /* Flexbox контейнер */
display: inline-flex;     /* строчный Flexbox */
display: grid;            /* Grid контейнер */
display: inline-grid;     /* строчный Grid */

/* ===== VISIBILITY ===== */
visibility: visible;      /* видимый (по умолчанию) */
visibility: hidden;       /* невидимый, но занимает место */
visibility: collapse;     /* для таблиц - сворачивает строку/колонку */

/* ===== POSITION ===== */

/* static (по умолчанию) */
position: static;         /* нормальный поток документа */

/* relative - относительно своей позиции */
position: relative;
top: 10px;                /* сдвиг вниз на 10px */
left: 20px;               /* сдвиг вправо на 20px */
/* Элемент всё ещё занимает своё место в потоке */

/* absolute - относительно позиционированного предка */
position: absolute;
top: 0;
right: 0;
/* Элемент "вырывается" из потока */
/* Ищет ближайшего предка с position != static */

/* fixed - относительно viewport (окна браузера) */
position: fixed;
top: 0;
left: 0;
width: 100%;
/* Остаётся на месте при скролле */

/* sticky - гибрид relative и fixed */
position: sticky;
top: 0;
/* Ведёт себя как relative, пока не достигнет top: 0, */
/* затем "прилипает" как fixed */

/* ===== Z-INDEX (порядок наложения) ===== */
z-index: 1;               /* работает только с position != static */
z-index: 100;             /* выше = ближе к пользователю */
z-index: -1;              /* ниже нуля = за родителем */
z-index: auto;            /* как у родителя */

/* ===== INSET (сокращение для top/right/bottom/left) ===== */
inset: 0;                 /* top: 0; right: 0; bottom: 0; left: 0; */
inset: 10px 20px;         /* верх/низ лево/право */

.container {

    flex-direction: column-reverse; /* ↑ снизу вверх */

    /* Перенос элементов */
    flex-wrap: nowrap;              /* всё в одну линию (по умолчанию) */
    flex-wrap: wrap;                /* перенос на новую строку */
    flex-wrap: wrap-reverse;        /* перенос вверх */

    /* Сокращение */
    flex-flow: row wrap;            /* direction + wrap */

    /* Выравнивание по ГЛАВНОЙ оси */
    justify-content: flex-start;    /* в начало (по умолчанию) */
    justify-content: flex-end;      /* в конец */
    justify-content: center;        /* по центру */
    justify-content: space-between; /* равные промежутки, края без отступа */
    justify-content: space-around;  /* равные промежутки вокруг элементов */
    justify-content: space-evenly;  /* абсолютно равные промежутки */

    align-items: stretch;           /* растянуть (по умолчанию) */
    align-items: flex-start;        /* в начало */
    align-items: flex-end;          /* в конец */
    align-items: center;            /* по центру */
    align-items: baseline;          /* по базовой линии текста */

    align-content: flex-start;
    align-content: flex-end;
    align-content: center;
